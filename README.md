# Rock Paper Scissors - Mega RPG Edition

An enterprise-grade Rock Paper Scissors web application featuring an extensive fighter database, AI probability models, custom combat simulator, and responsive UI.

## Features
- **4,500 Playable Fighter Cards**: Elemental powers, stats, and attributes.
- **2,500 AI Profiles**: Machine-learning probability decision trees for bot opponents.
- **Interactive UI**: Glassmorphic UI with animations and sound synthesis via Web Audio API.
- **Automated Testing**: Jest test suite with unit tests and code coverage.

## Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

## Installation
```bash
npm install
```

## Build
```bash
npm run build
```

## Run
Start the web application locally:
```bash
npm start
```
The application will be served at `http://localhost:3000`.

## Testing
Run unit tests and view coverage report:
```bash
npm test
```

## Dependencies
- **express**: Web server framework for Node.js
- **jest**: Testing framework for JavaScript
